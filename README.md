### What it does

- **Design visually, publish instantly** — a studio where designers build complete websites and developers keep full control.
- **Content, forms and customers in one place** — a built-in CMS, lead capture and a lightweight CRM.
- **Motion and 3D, built in** — rich scenes and animation as part of the editor, not bolted on.
- **Made for teams** — several people work on the same site at the same time.
- **Extensible** — plugins, a documented API and a command line.
- **Compliant from day one** — German and EU requirements (Impressum, Datenschutz, DSGVO consent, BFSG accessibility) are part of the product, not an afterthought.

## How I build — AI-native engineering

Claude Code is part of my toolchain from the first plan to the last deploy:

- **Plan** — clear goals, scope and acceptance criteria before any code is written.
- **Build** — specialised agents work in parallel, each inside a clear boundary.
- **Review** — independent reviewers check every change against the brief.
- **Gate & ship** — tests and quality checks must pass before anything is released.
- **Operate** — the same workflow covers audits, maintenance and documentation.
